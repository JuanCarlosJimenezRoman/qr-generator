Privacidad

Resumen corto: el contenido de tus códigos QR (enlaces, WiFi, contactos, mensajes) nunca sale de tu navegador. Lo único que se mide es tráfico agregado y anónimo del sitio, con Vercel Analytics.

El generador de QR en sí

Esta aplicación es 100% del lado del cliente: no hay backend ni base de datos. Todo lo que escribes en el formulario (una URL, los datos de tu red WiFi, un número de WhatsApp, los campos de una vCard) se procesa con JavaScript directamente en tu navegador para generar el código QR. Nada de eso se envía, ni a nuestros servidores ni a ningún tercero. El código es abierto en GitHub si quieres confirmarlo tú mismo.

Vercel Analytics

Para entender cuánta gente usa el sitio y desde dónde, usamos Vercel Web Analytics. Es un servicio de medición sin cookies: identifica visitas con un hash calculado a partir de la petición, que se descarta a las 24 horas, en vez de guardar un identificador permanente en tu navegador.

Qué datos recibe Vercel por cada visita
  • La página que visitaste (por ejemplo /guias/qr-wifi/) y de dónde venías (referrer).
  • Ubicación aproximada (país / región / ciudad, no la IP exacta).
  • Tipo de dispositivo, sistema operativo y navegador.
  • Fecha y hora de la visita.

Estos datos se reportan de forma anónima y agregada: no se usan para identificarte, ni para armar un perfil que te siga entre distintos sitios web, ni se cruzan con el contenido que generas en el QR (ese, como se explicó arriba, ni siquiera llega a un servidor).
